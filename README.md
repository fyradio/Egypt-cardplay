# 太陽船之書（埃及神話卡牌）

一款以埃及神話故事為主的卡牌對決遊戲。一章一個神話故事，用一場特殊規則的對決來演出；打贏就解鎖故事、收集神祇卡，每張卡背面都有「神話小檔案」（出處、版本差異、親子討論題）。

- 對象：11 歲以上，適合親子一起玩、一起讀
- 形式：橫向手機／電腦，單機對 AI，離線可玩
- 發佈：GitHub Pages（多檔案專案）
- 版面：手機直式為主（見 `sim.html`）
- 遊戲網址（開啟 Pages 後）：https://fyradio.github.io/Egypt-cardplay/

## 目前狀態

**美術階段：主風格樣張第一版。** 這次美術與卡牌品質優先，樣張通過後才開工做對決遊戲。

- 卡牌試看頁：[`cards.html`](cards.html)（開啟 Pages 後：https://fyradio.github.io/Egypt-cardplay/cards.html ）——基本卡、進化線、三神（各有專屬光影）、合成與融合怪、場地卡、燙金卡背、立體翻牌、神話小檔案
- 對戰畫面：[`sim.html`](sim.html)（開啟 Pages 後：https://fyradio.github.io/Egypt-cardplay/sim.html ）——兩個 AI 在牌桌上實際對戰：真實卡牌、手牌、召喚／進化／合成／攻擊／受傷動畫，附播放／暫停／重新開始、單步、速度、看乙的手牌、戰況紀錄
- 文字版對戰說明：[`sim-text.html`](sim-text.html)——同一套模擬，用文字逐步解釋每個動作
- 完整企劃：[`docs/埃及神話卡牌-企劃.md`](docs/埃及神話卡牌-企劃.md)

## 美術主風格

取自使用者提供的四張明信片（只當風格參考，構圖全部自己畫）：

- **紙草壁畫風**：土黃紙草底、黑色描線、平塗礦物色——一般卡
- **黑底燙金風**：細金線、松石綠與玫瑰銅點綴——神話卡、三神、卡背
- 卡圖全部用程式（SVG）畫，象形文字是真的、可讀的內容

## 企劃重點

- **故事戰役**：序章＋10 章＋終章（創世、太陽船夜航、奧西里斯之死、伊西斯尋夫、荷魯斯對賽特、拉的真名、心的秤重、毀滅之眼、法老與眾神…），每章標示主要出處。
- **500＋ 張卡**：怪獸、魔法、陷阱，加上進化（一階→二階→三階）、合成、融合、死者復活、墓穴陷阱，以及取材自真實神學的「三神」（阿蒙、拉、普塔）。
- **收集養成**：卡包（含保底、不做付費抽卡）、升星、神殿建設、聖甲蟲夥伴。
- **知識挑戰**：托特的考驗、象形文字教室。
- 不放廣告、不收集資料。

## 更新流程

1. 在 Claude 對話裡討論、修改
2. 跟 Claude 說「上傳」，Claude 會把有改的檔案推送到 `main`，並遞增 `sw.js` 的快取版本
3. 等 1～2 分鐘，玩家下次連網開啟就會自動更新

## 開啟 GitHub Pages（只需一次）

儲存庫 → Settings → Pages → Source 選 **Deploy from a branch** → Branch **main**、資料夾 **/(root)** → **Save**。

## 存檔

存檔放在各自的手機／瀏覽器裡，不會同步；規劃提供短存檔碼匯出／匯入，換手機時使用。
