# 埃及神話卡牌（暫名：《太陽船之書》）

一款以埃及神話故事為主的卡牌對決遊戲。一章一個神話故事，用一場特殊規則的對決來演出；打贏就解鎖故事、收集神祇卡，每張卡背面都有「神話小檔案」（出處、版本差異、親子討論題）。

- 對象：11 歲以上，適合親子一起玩、一起讀
- 形式：橫向手機／電腦，單機對 AI，離線可玩
- 發佈：GitHub Pages（多檔案專案）
- 遊戲網址（開啟 Pages 後）：https://fyradio.github.io/Egypt-cardplay/

## 目前狀態

**企劃階段（v0.2），尚未開工。** 完整企劃見 [`docs/埃及神話卡牌-企劃.md`](docs/埃及神話卡牌-企劃.md)。

## 企劃重點

- **故事戰役**：序章＋10 章＋終章（創世、太陽船夜航、奧西里斯之死、伊西斯尋夫、荷魯斯對賽特、拉的真名、心的秤重、毀滅之眼、法老與眾神…），每章標示主要出處。
- **500＋ 張卡**：怪獸、魔法、陷阱，加上進化（一階→二階→三階）、合成、融合、死者復活、墓穴陷阱，以及取材自真實神學的「三神」（阿蒙、拉、普塔）。
- **收集養成**：卡包（含保底、不做付費抽卡）、升星、神殿建設、聖甲蟲夥伴。
- **知識挑戰**：托特的考驗、象形文字教室。
- 不放廣告、不收集資料。

## 專案結構（規劃）

```
index.html            入口
css/style.css         樣式
js/engine.js          對決規則
js/ai.js              AI（三種難度）
js/ui.js              畫面與卡牌繪製
js/story.js           章節與過場
js/save.js            存檔與匯出／匯入碼
data/cards/*.json     卡片資料
data/story/ch01.json… 每章故事與對話
data/codex.json       神話小檔案
assets/               SVG 零件、圖、音效
sw.js                 離線快取
docs/                 企劃與文件
```

## 更新流程

1. 在 Claude 對話裡討論、修改
2. 跟 Claude 說「上傳」，Claude 會把有改的檔案推送到 `main`，並遞增 `sw.js` 的快取版本
3. 等 1～2 分鐘，玩家下次連網開啟就會自動更新

## 開啟 GitHub Pages（只需一次）

儲存庫 → Settings → Pages → Source 選 **Deploy from a branch** → Branch **main**、資料夾 **/(root)** → **Save**。

## 存檔

存檔放在各自的手機／瀏覽器裡，不會同步；規劃提供短存檔碼匯出／匯入，換手機時使用。
